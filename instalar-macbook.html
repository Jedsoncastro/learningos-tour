LearningOS no MacBook Air

Deixe o MacBook Air igual ao Mac mini

Abra esta página no MacBook Air. Toque em cada passo, aperte os botões Copiar, cole no Terminal e, no fim do passo, aperte Concluí. A página guarda onde você parou.

Onde fazer cada passo: MacBook Air Mac mini
  1. Aperte Cmd + Espaço (abre a busca do Mac).
  2. Digite Terminal e aperte Enter. Abre uma janela de texto.
  3. Deixe essa janela aberta ao lado desta página até o fim.
Quando o Terminal pedir a senha do Mac, ela não aparece enquanto você digita. É normal: digite e aperte Enter.

O Homebrew é o "instalador de programas" que baixa o resto sozinho.

  1. Copie, cole no Terminal (Cmd + V) e aperte Enter. Ele pede a senha e depois outro Enter.
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  2. Se aparecer uma janela da Apple pedindo para instalar "ferramentas de linha de comando", aceite e espere.
  3. Quando o Terminal voltar a ficar parado, copie e cole este segundo comando:
    echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile && eval "$(/opt/homebrew/bin/brew shellenv)" && brew --version
Deu certo se aparecer Homebrew seguido de um número.

O projeto é privado. Sem este login, o Air não consegue baixar o código.

brew install gh && gh auth login
  1. Responda com as setas e Enter, nesta ordem: GitHub.com, HTTPS, Yes, Login with a web browser.
  2. O Terminal mostra um código de 8 letras. Aperte Enter: o navegador abre.
  3. Entre na sua conta do GitHub, cole o código e clique em Authorize.
Deu certo se o Terminal mostrar Logged in as e o seu usuário.
Este passo é no Mac mini. A chave da IA não fica no GitHub, de propósito. Ela passa para o Air pela mesma conta Apple, sem criar arquivo.
  1. No Mac mini, abra o Terminal (Cmd + Espaço, Terminal).
  2. Cole este comando e aperte Enter. Não aparece nada: é normal. Abra esta página no Mac mini também, ou digite o comando.
    grep '^ANTHROPIC_API_KEY=' ~/Developer/learningos/.env | cut -d= -f2- | pbcopy
  3. Volte ao Air e faça o passo 5 logo em seguida (em até 2 minutos).
Sem a chave, tudo funciona com IA simulada e dá para colocar a chave depois. Se não passar de um Mac para o outro, confira em Ajustes do Sistema, Geral, AirDrop e Handoff, se o Handoff está ligado nos dois.

Um comando só. Ele baixa o projeto, instala o que falta e liga o banco de dados.

mkdir -p ~/Developer && cd ~/Developer && { [ -d learningos ] || gh repo clone castro-ai-labs/learningos; } && cd learningos && git pull --ff-only && bash scripts/instalar-mac.sh
  1. Ele mostra 7 etapas, cada item com [ok] quando fica pronto.
  2. Quando pedir a chave da Anthropic: Cmd + V e Enter. A chave não aparece na tela.
  3. Na última etapa ele instala e abre o Docker. Aceite os termos na janela dele (pode pular o cadastro). O script espera até 5 minutos.
  4. Terminou quando aparecer PRONTO.
Se aparecer uma linha começando com PAROU:, ela diz o que fazer. Resolva e cole o mesmo comando de novo: o que já ficou pronto é pulado.

No mesmo Terminal, cole e aperte Enter:

cd ~/Developer/learningos && set -a && source .env && set +a && ./scripts/demo.sh

Espere a frase demo: abra http://localhost:3000. Depois toque nos botões abaixo, nesta ordem:

Abrir o app Caixa de e-mails de teste
  1. No app, clique em Criar conta.
  2. Na caixa de e-mails de teste, abra Confirme seu e-mail e confirme.
  3. Crie um espaço, envie seu material e peça para a IA preparar.
O app desliga sozinho em 2 horas (ou Ctrl + C no Terminal). Para ligar de novo outro dia: abra o Docker e repita só este passo.

MacBook Air pronto

O LearningOS agora roda nos dois Macs. Veja abaixo como continuar o projeto entre eles.

Continuar o projeto nos dois Macs e no celular

Ao começar a trabalhar num Mac

Abra o Claude Code na pasta do projeto e peça: "puxa as novidades do GitHub". Ele traz o que foi feito no outro Mac.

Ao terminar

Peça: "salva no GitHub". Sem isso, o outro Mac não vê o que foi feito. Evite mexer no mesmo assunto nos dois Macs ao mesmo tempo.

Claude Code no MacBook Air

Instale o seu kit de regras e skills pelo arquivo INSTALAR-NO-MAC-2.md do repositório meu-kit-claude. Assim o Air trabalha com as mesmas regras do Mac mini.

Pelo celular

No app Claude, a aba Code trabalha direto no projeto do GitHub, na nuvem: dá para pedir mudanças e aprovar PRs. Ligar o app no celular não dá: ele precisa do Docker, que só roda no Mac.

O que não passa de um Mac para o outro

As contas e materiais de teste (cada Mac tem o seu banco), a chave da IA (vai uma vez, no passo 4) e as anotações que o Claude guarda no Mac mini. Para ter os mesmos dados em todo lugar, o app precisa ser publicado na internet, decisão que ainda é sua.

Se algo der errado

"command not found: brew" ou "gh"

Feche o Terminal (Cmd + Q), abra de novo e repita o comando. Se continuar, refaça o passo 2.

Pede senha do GitHub ou "Could not resolve to a Repository"

O login do passo 3 não foi feito, ou foi com outra conta. Repita o passo 3.

"isso nao parece uma chave da Anthropic"

A cópia do passo 4 não chegou. Refaça o passo 4 e cole o comando do passo 5 de novo. Nada foi gravado.

"o Docker nao ficou pronto"

Abra o app Docker, aceite os termos e espere a baleia no alto da tela parar. Depois cole o comando do passo 5 de novo.

O mesmo erro apareceu duas vezes

Pare e mande um print do Terminal para o Claude no Mac mini.
